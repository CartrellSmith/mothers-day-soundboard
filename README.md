🌸 Mother’s Day Soundboard

A simple, joyful, interactive soundboard built to celebrate Mother’s Day — featuring soft pastel styling, floating heart animations, keyboard controls, and a clean, accessible UI.
🌐 Live Demo

👉 View on GitHub Pages

💖 Preview
A lightweight soundboard where each button plays a unique sound when clicked or pressed on the keyboard. Designed with a soft Mother’s Day theme using a custom pink palette.
✨ Features

    10 unique sound buttons (Birds, Chime, Clapping, Harp, Heartbeat, I Love You, Kid Giggle, Thank You, Waterfall, Wind)

    Keyboard support (keys 0–9)

    Floating heart animations on click or keypress

    Button press animation with soft color transitions

    Clean pastel Mother’s Day theme

    Responsive grid layout for mobile and desktop

    Lightweight, fast, and accessible

🎨 Color Palette
